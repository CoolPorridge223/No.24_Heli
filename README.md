# 24号直升机 / No.24 Heli

Minecraft 1.21.1 · Fabric Loader 0.19.2 · Fabric API 0.116.17+1.21.1 · Java 21 及以上。

## 安装

将 `build/libs/No.24_Heli-1.3.1b.jar` 放入游戏实例的 `mods` 文件夹，同时安装匹配的 Fabric API。联机时客户端和服务器都要更新到 1.3.1b。本模组不需要额外动画库，MP3 解码库已内置。不要安装带 `-sources` 的源码包；同一游戏实例只安装一个版本的本模组，保留的旧 JAR 放在备份位置。

## 第一次飞行

1. 在空旷位置右键方块放置“24号直升机”，机头朝向与你一致。主旋翼周围留出至少 4 格空间。
2. 手持任意普通物品（例如煤油）蹲下右键机身打开燃油/货仓；将煤油放入左上燃料槽。落地时每秒消耗 1 份补给，煤油补充 150 单位，原油补充 80 单位。新造飞机没有燃油。
3. 空手右键登机，自动切换到拉远的第三人称并隐藏机内乘员模型。第一位为驾驶员，第二位为副驾驶。按 **R** 启动，等旋翼达到 100%：休闲模式约 5 秒，曼巴模式约 12 秒。
4. 按住 **空格** 逐渐增加总距；约 56% 是完好、水平、晴天的悬停起点。转速未满时抬总距也无法离地。起飞后通过 H 保持高度，W 推杆前飞。
5. 降落时松开巡航，S 拉杆减速、J 配平、G 放下起落架，再用左 Ctrl 减小总距缓降。接地后将总距降到 0，再按 R 关闭引擎，等待旋翼停转。

**R 在空中也能切断动力，会进入无动力自转下降，不能当作普通降落按钮。** 旋翼需要时间停转，地面大修与涂装须等待完全停转。

## 操作表

除鼠标飞控、Q/E 和左 Ctrl 外，专用按键可在游戏“选项 → 控制 → 按键绑定 → 24号直升机”调整。Q/E 与原版丢弃/背包默认键重叠，驾驶时由模组接管；其他按键冲突也可在此修改。

| 输入 | 功能 |
|---|---|
| W / S | 低头前飞 / 抬头减速，保留惯性 |
| A / D | 左右侧倾与侧滑 |
| 鼠标上下 / 左右移动 | 离地后控制俯仰 / 横滚；N 切换鼠标操纵与自由观察 |
| 鼠标中键（可重绑） | 视角锁定，平滑跟随机头方向；再次点击取消 |
| 空格 / 左 Ctrl | 增加 / 减小总距；松手保持当前总距 |
| Q / E（或可重绑的 Z / V） | 左右脚蹬，控制偏航与手动抗扭 |
| R | 引擎启停；两次切换之间至少 1 秒 |
| H | 高度保持；手动改总距时重新记录目标高度 |
| J | 自动配平；关掉后松杆会保留机身姿态 |
| I | 巡航保持当前空速；手动前后操纵更新目标速度 |
| G | 收放起落架 |
| B | 悬停时部署/收回绳索 |
| Y | 机内挂到绳索顶部；外部靠近任意绳段时吸附，均不自动上下 |
| O | 打开燃油/货仓界面 |
| M | 乘机时打开 / 关闭导航地图；Esc 也可返回，未登机不能打开 |
| N | 切换鼠标操纵 / 自由观察 |
| U | 开启 / 关闭自动驾驶；需要导航点且离地至少 10 格 |
| K | 休闲模式一键起飞 / 降落；再次按下取消 |
| 按住 Tab | 打开八槽电台圆盘，移动鼠标选曲，松手确认；中心为关台，Esc 取消 |
| 鼠标滚轮 | 第三人称乘机时调整相机距离；地图内缩放地图 |
| Shift | 地面/水中立即下机；空中首次警告，松开后 3 秒内再次按下确认。绳上离地 ≤3 格直接脱离，>3 格也须两次确认 |
| 绳上 W / S / E | 按住 W 上升、S 下降，松开停住；到顶按 E 进入空闲副驾 |

登机隐藏快捷物品栏（货仓 O 仍可使用），下机恢复。相机初始距离为 10 格，可用滚轮在 4–24 格之间调整，遇到墙壁自动缩短以避免穿墙；F5 仍可切换视角，下机恢复登机前的视角。“视角锁定 / 取消”默认中键，可在原版控制菜单改为键盘或其他鼠标键；N 单独控制鼠标是否参与飞控。旧版默认 K 会一次性迁移到 J；其他自定义绑定保持原值。旧版默认鼠标操纵切换 M 一次性迁移到 N，为地图让出 M。

驾驶员空中离机后，飞机先尝试稳定悬停约 3 秒，再逐渐倾斜、自旋并失去动力下坠，不会保留高总距一直爬升。重新登机可中断无人驾驶程序；若已失去动力，需要重新启动并修正姿态。严重损伤或缺油时不能保证悬停。

## 生存获取

获得铁锭后，模组合成配方会加入原版配方书。

**整机路线**：工作台按下列图案合成；I=铁块，G=玻璃，F=铁锭，C=高炉，R=红石块。

```text
I G I
F C F
I R I
```

**部件路线**：分别合成机身、旋翼总成、尾桨、引擎模块、燃油罐。将这五种物品各一份放在背包里，手持机身右键停机坪，自动检查空间并消耗材料完成组装。创造模式免材料消耗。停机坪为直径 **10 格**、厚 **0.25 格**的圆盘，中间有白色大 H 与黄色边环。黄色边环内均匀布置 **16 盏暖黄色指示灯**，灯体不超出边线，白天自动熄灭、夜晚自动开启。停机坪底座和标记均不自发光，亮度随环境光照变化。放置时整个圆盘范围需要空闲，且不得与禁飞区相交或相切；拒绝放置时不消耗物品。只消耗一个物品，任意位置右键机身都在中心组装，停机补给在整个平台上有效。破坏任意一处拆除整个圆盘，只掉落一个停机坪。旧存档的单块停机坪请拆下后在空地重新放置。

| 部件/补给 | 原料 |
|---|---|
| 旋翼总成 | 4 铁锭 + 1 红石，十字排列 |
| 尾桨 | 4 铁粒环绕 1 铁锭 |
| 引擎模块 | 6 铁锭 + 2 红石 + 1 熔炉 |
| 燃油罐 | 8 铁锭围成空心方框 |
| 机身 | 7 铁锭 + 1 玻璃 + 1 箱子 |
| 维修包 ×2 | 2 铁锭 + 1 铁粒 + 1 红色染料 |
| 停机坪 ×4 | 2 铁锭 + 1 黄色染料 + 3 平滑石头 |
| 原油 | 2 煤炭 + 1 玻璃瓶，无序合成 |
| 煤油 | 熔炉冶炼原油，10 秒 |
| 涂装 | 对应染料 + 铁粒 + 玻璃瓶，无序合成 |

放置停机坪时，H 随放置者当时的水平朝向确定为东西向或南北向；放好后保持固定。停机坪显示范围跟随已加载地形的视距，不再额外受 64 格渲染距离限制。

原油采用原版材料合成，不新增矿物或世界生成。燃料为一次性补给物品，不返还玻璃瓶。

## 燃油、维护与损伤

- O 界面提供独立燃料槽和 **18 格货仓**，支持原版拖动、分堆及 Shift 快速转移。空中可使用货仓，但不能通过燃料槽空中加油。
- 停机坪上落地停机后，会自动把货仓中的煤油/原油移到燃料槽。启动自检检查燃油、引擎与主旋翼。
- 悬停较省油，高速飞行提高油耗，大幅推杆、侧滚和连续改总距会明显增加油耗。受损引擎功率下降且更耗油。
- 主旋翼、尾桨、引擎、油箱分别保存耐久，另有机身总耐久。外部攻击的方向与高度决定受损部件；机上乘员的近战和可归因的投射物不会损伤本机。创造乘员的自身飞行在机内禁用，空格仍控制直升机总距，下机后创造飞行能力保留。
- 主旋翼受损降低升力并引起抖动；曼巴模式尾桨失效会持续自旋，需 Q/E 手动抗扭。
- 油箱低于 80% 会漏油，即使停机也会继续漏。
- 地面停转时，手持维修包右键机体：各部件和机身恢复 30 点，每秒最多维修一次。驾驶中手持维修包右键可应急修复 3 点，每 10 秒一次，**不能空中补油箱**。
- 空中撞墙、撞顶仍会解体爆炸；微小接触抖动除外。与动物等非玩家实体相撞时，相对速度不超过 10 m/s（36 km/h）只伤害被撞实体，不伤害或炸毁飞机；超过门槛才按撞击强度计算机损与爆炸。玩家接触不会触发碰撞事故，地面和刚放置阶段忽略实体接触。正常低速着陆与地面低速擦碰只会按冲击扣耐久，高速撞地会爆炸并对乘员造成致命伤害。起落架收起或大倾角接地，更容易发生严重事故。
- 解体会掉落货仓物资，并留下可保存的残骸；蹲下右键残骸可回收部分铁粒，并有概率回收尾桨。

## 整机回收

所有乘员下机后，关闭引擎并等待旋翼停转，**空手蹲下右键**即可回收整机。要求机体落地停稳，或入水后速度降低；引擎完全损坏也可回收。入水会切断动力并增加阻尼，等待数秒再操作。

整机物品保存燃油、各部件及机身损伤、涂装、导航点和全部货仓。重新放置仍是原来的损伤状态，不会免费修复；运动、旋翼、引擎启停与自动驾驶重置。创造模式放置带存档的回收机也会消耗该物品，避免复制货仓。残骸仍按原方式回收零件。手持煤油等普通物品蹲下右键可打开货仓；维修包、涂装保留各自交互。

## 地图、导航与禁飞区

- **M 打开/关闭地图**：仅乘机时使用。横向长方形北向地形图采用原版地图配色与纸色边框，**左键拖动、右键设点、滚轮缩放**，Esc 返回。黄色标记为导航点，红圈为禁飞区；禁飞区内禁止设点。地图使用 GPU 绘制分块纹理，按区块增量更新；拖动、缩放复用缓存，飞行时优先更新附近新地形，缩小时后台逐步补齐旧地形。已接收区块自动记录到本地，离开、卸载或重进世界后仍可显示；纸色区域为尚未记录的地形。缓存从该客户端开始记录地形时积累，不能追溯记录前已卸载的区块，也不强制加载远方世界。
- 地图上的白色无柄导航箭头表示自己乘坐的飞机，橙色小一号箭头表示其他飞机，尖端与机头方向一致。停机坪是地图上的**固定圆形 H 标记**，H 按可见笔画居中且无阴影；离开雷达范围、卸载区块或重进世界后仍保留；实际拆除时移除。**直接点击圆形 H 即可设为导航点**。旧停机坪被禁飞区覆盖时显示红色圆形 H，无法设置导航；普通右键设点同样不能绕过该限制。旧存档中尚未登记的停机坪在所在区块首次加载时自动加入目录。机载雷达使用独立扫描结果，只显示 **512 格内已加载的停机坪**，超出范围后从雷达消失。更新此功能时客户端和服务端须一起替换 JAR。
- **U 自动驾驶**：驾驶员或副驾驶均可设点/清除导航点；更换导航点会取消当前自动任务，需再次按 U 规划。仅驾驶员可在启动、离地至少 10 格并松开操纵键后按 U 开启自动驾驶。飞机首次规划时先制动悬停，后台一次性生成安全曲线和速度表，再连续跟随。途中禁飞区变化时后台验证旧轨迹，仍安全则复用；需要绕行时重新规划，前方已不安全则先制动。默认巡航目标 **75 km/h**，可配置至 **80 km/h**；弯前按曲率提前减速、弯中协调偏航与侧倾、出弯恢复加速，中间路径点不要求停车。实际速度受转弯、制动、风、机况及服务器 TPS 影响。到达最终导航点后，自动驾驶退出并保持悬停。任意有效方向、脚蹬、总距或鼠标飞控输入都会立即退出；引擎/飞控辅助切换同样交还控制权。N 自由观察时转动视角不算操纵。佐巴扬模式禁止自动驾驶。
- 平面路线使用 **八邻接 A* → 安全 Bezier 曲线 → 连续前视跟踪 → 速度和姿态反馈控制**。网格只供后台规划，默认每格边长 2 格，不驱动飞机逐格移动；斜向通行禁止切过障碍角。全部禁飞圆按飞机水平碰撞箱外接圆（当前约 2.404 格）与安全余量（默认 2 格）扩张。优先为转弯预留更宽空间，窄通道再按原安全范围求解；曲线完整采样段均通过几何检查，无法安全执行的曲线会明确报错并制动悬停。实际运动仍使用原有旋翼物理和碰撞系统。
- 起点或终点位于真实禁飞圆内或边界上时拒绝规划；需要先手动驶离或更换导航点。两点相同且合法时直接报告已到达。区域被禁飞圆围住并不自动判为不可达：同一封闭区域内仍允许导航，只有确实不连通才报告封闭原因。合法坐标被整格阻挡或窄通道无法表示时，会有限细化网格（最多三轮，最细 0.25 格）；仍未解决则提示精度或资源限制，不能当作物理上无路。网格、搜索节点或几何运算超过预算时明确报告资源限制，飞机制动悬停；可主动接管、修改配置或更换导航点。
- 原有高度保持、地形前视与手动接管继续生效。前方沿路线最多 256 格的已加载地形会提前参与高度规划，逐步抬高目标高度并按剩余距离降低水平速度，保留至少 10 格地形净空；近障仍检查机体、旋翼和惯性扫掠通道。未加载地形、隧道顶、世界边界或没有安全通道时制动等待。二维 A* 只处理禁飞区，不提供建筑或地形迷宫中的完整三维寻路，也不自动起降；严重损伤或动力不足仍可能失高。落地、入水、失去驾驶员或动力会退出，存档重载后须手动重新开启。
- **禁飞区雷达**：用 3 铁锭、1 指南针、1 红石合成（上排中间铁锭，中排“铁锭/指南针/铁锭”，下排中间红石），放置后默认建立半径 64 格禁飞区。右键打开设置，可输入 **16–512 格**；仅放置者或管理员能修改。
- 禁飞区为全高度圆柱，仅在所在维度生效。区块卸载不会关闭禁飞区，破坏雷达会删除该区；不再设置每维度固定的禁飞区数量上限，规划仍受网格及运算预算限制，网络快照受游戏数据包大小限制。飞机进入后，乘员会收到文字和周期声音警报。禁飞区目前只告警，不强制击落或阻挡手动飞行。

## 一键起降与机载电台

**休闲模式按 K**：地面自动启动、预转并爬升约 10 格，完成后保持高度；空中自动减速并垂直降落，真正接地后关闭引擎。头顶需有完整起飞空间，降落点中心和四角需是干燥、接近同高的支撑面，飞机还需有燃油及足够的引擎/旋翼耐久。再次按 K 或主动操纵会接管取消。它不具备自动避障能力，曼巴和佐巴扬模式均不能使用。

电台仅预留 **8 个槽位，不内置音乐**，文件依次命名为 `slot_1.mp3` 至 `slot_8.mp3`。**单人游戏放在本地游戏实例的 `config/no_24_heli_radio/`；多人游戏由服主放在服务器的同名目录**。局域网开放世界由房主提供文件。多人客户端无需自行放歌，也不会使用自己目录中的同名文件替代服务器歌曲。不必填满，空槽位显示“空”。

驾驶员和副驾驶均可按住 Tab、移动鼠标选择槽位后松手播放，选圆盘中心停止。多人首次听到某首歌时自动从服务器后台分片获取，不向玩家显示正在加载音乐的提示，完成校验后按当前进度播放；同一次连接内后续使用缓存，无需重复下载。服务器单曲上限 **32 MiB**，添加或更换歌曲后重启服务器/局域网世界以刷新目录。单人新增文件后重新打开圆盘即可看到，替换当前歌曲后先关台再重选。音乐来源统一为 config，不再使用资源包歌曲后备。

音乐循环播放，后来靠近的玩家从对应进度接入。机内音量不受第三人称镜头远近影响，其他玩家按自身到飞机的距离衰减，64 格外无声；受游戏“唱片机/音符盒”和主音量控制。禁飞警报也不再随镜头拉远而变小。多人下载缓存位于客户端 `config/no_24_heli_radio_cache/`，退出世界、断开服务器或正常关闭游戏时自动清除，下次进入后按需重新获取；自己的 `config/no_24_heli_radio/` 原始音乐不会删除。客户端与服务端均需替换为本次修订包，版本号仍为 **1.2.1**。

## 自转迫降

动力丢失后，先降低总距，让下降气流维持旋翼转速；保持机身接近水平和适当的前飞速度。接近地面时拉杆减速并逐渐增加总距，利用旋翼储存的能量减小接地速度。过早大总距会耗尽旋翼能量，过晚拉平会高速撞地。优先放下起落架，避开建筑、水面和陡坡。

这是面向游戏的简化直升机物理，不是现实航空训练程序。高度表是世界 Y 坐标；垂直速度单位为 m/s，空速按 1 格≈1 米换算显示为 km/h。

## 乘员、绳降与涂装

驾驶员先登机，再让第二位玩家右键登机。可用拴绳将附近 5 格内未乘坐载具的村民装入空余座位。村民无法驾驶。请由驾驶员登机后手持拴绳右键装载村民。

放绳要求直升机距下方地面 **大于 3 格、不超过 24 格**、水平速度低于 2 m/s、垂速绝对值低于 1.5 m/s。驾驶员按 B 部署，机内玩家按 Y 下绳；副驾驶座的村民在部署时自动下绳。同一根绳可挂多名玩家，各自独立移动；绳上有人时不能收绳，可携带悬挂人员飞行。空绳在飞行中保持展开，按 B 收回。

玩家靠近任意绳段（约 3 格内）按 **Y** 吸附。按住 **W** 上升、**S** 下降，松开立即停住；速度约 2.8 / 4.6 m/s。到顶后按 **E** 进入空闲副驾驶座，满舱则继续悬挂，不自动入舱或成为驾驶员。总绳长取初始展开长度与当前离地净空的较小值，不随玩家位置收缩。整绳分段模拟惯性，可摆动、弯曲；机身离开视野仍可看见绳段。

绳上按 **Shift** 可主动脱离：离地不超过 3 格时立即释放；超过 3 格时，先警告，松开后须在 3 秒内再次按下确认。主动高空脱离后正常承担后续坠落风险；玩家到达地面后按 Shift 解绳，村民仍自动安全落地。

绿色、白色、黄色、黑色、橙色染料分别合成丛林、雪地、沙漠、纯黑、救援橙涂装。新增**紫金24号涂装**：紫色染料 + 黄色染料 + 铁粒 + 玻璃瓶，无序合成；紫色机身、金色饰带，机身左右两侧都有金色“24”。落地并等待旋翼停转后，手持涂装右键机身。涂装只改变外观。

## 难度与配置

在游戏“选项”中打开 **直升机设置**。**我的飞行模式**由每名玩家独立选择，普通玩家也能修改，按 UUID 保存在当前服务器存档中，跨维度、重登及重启保留。飞机按当前驾驶员的模式运行；副驾驶修改自己的模式不影响本机，接任驾驶后才生效。无人驾驶时沿用最后模式。

**全服爆炸破坏 / 着火**仍由房主或具有 2 级权限的管理员统一修改，普通玩家只能查看。关闭后不破坏方块、不点火，但事故爆炸及乘员致命伤害仍存在。

个人模式切换无需重启，仅重置自己正在驾驶的飞机的辅助并取消自动任务；燃油、部件耐久、速度和总距保留。切回休闲默认打开配平与高度保持，**巡航在所有模式下都默认关闭**。

HUD 最左下角为燃油、旋翼转速、总距三个表盘，上方为机身模式与自动控制状态。机组信息竖排四行：主驾、主驾姓名、副驾、副驾姓名；空座显示“空座”。底部保留五段连续耐久条。空速表左侧从左到右为垂速、高度两个等大的滚动仪表，顶部显示 m/s 和 m。“垂速”和“高度”标题放大为此前的 1.5 倍。两表刻度与数字统一靠左；垂速每 5 m/s 一条短刻度，整 10 m/s 为带数字的长刻度；高度每 50 米一条短刻度，整 100 米为带数字的长刻度。垂速正值带 +、负值带 -，零刻度只写 0。

两个仪表中央都有箭头固定向左的放大数字窗，外框为向左凸字形：左侧符号和高位区域较矮，右侧低位区域上下加高。垂速仅个位在加高框内连续滚动，十位、百位各只显示一个数字，进位或借位时由下一位滑入、当前位滑出；高度仅十位和个位在加高框内按 00、20、40、60、80 连续滚动，百位及更高位同样采用单行替换。例如 710 米显示 700 与 720 之间的过渡，780 到 800 时百位同步进位。窗内数字与窗外刻度统一：数值增加时向下滚动，减少时向上滚动。正负号固定在窗内左侧中央，与左框保留边距，只显示一次，中心数字为零时隐藏；垂速正数显示 +、负数显示 -，高度正数不加 +、负数显示 -。两个仪表沿用 2/3 整体缩放，并与空速表底部对齐。刻度中心完全不透明，两端渐淡到 50%。高度仍为世界 Y；实际离地高度由近地提示提供。

飞行时按实际离地距离进入 **50 / 30 / 20 / 10 / 5 米**提示档。正常缓降、悬停和爬升只显示普通“离地 X m”，下降率超过当前档的 5 / 4 / 3 / 2 / 1.5 m/s 时显示“下降过快”。只有下降会触发语音事件，同档警告只触发一次，离开该档超过 1 米后重新进入才允许再次触发；接地、入水、未起飞和离机清除状态。语音回调已预留，目前没有附带语音素材。近地提示与世界高度表使用不同读数。

右上机载雷达半径为 **512 米**，机头方向为上，白色指针为本机，蓝点为玩家、橙点为完好飞机、金色菱形为导航点，红色弧线为禁飞区边界；超出 512 米的导航点钳在外圈指示方向。服务器每半秒提供同维度已加载目标的坐标快照，因此超出客户端完整实体跟踪距离的目标也可显示；不会为扫描强制加载远方区块，最多显示距离最近的 512 个目标。

视角锁定绑定仅在乘机且未打开界面时生效；离机后同键的原版操作保留。雷达方块使用非整块遮挡形状，底部不再使下方地形透视。

首次运行后生成 `config/no_24_heli.json`。其中 `difficulty` 仅作为尚未设置个人模式的默认值。手动修改文件后重启世界/服务器，联机以服务端配置为准。主菜单中的设置编辑本地默认值。

```json
{
  "difficulty": "CASUAL",
  "explosionBlockDamage": true,
  "wind": true,
  "rotorPreSpin": true,
  "fuelCapacity": 1200.0,
  "explosionPower": 5.0,
  "autopilotCruiseKmh": 75.0,
  "autopilotLookMin": 8.0,
  "autopilotLookMax": 30.0,
  "gridCellSize": 2.0,
  "pathSafetyMargin": 2.0,
  "pathBoundaryMargin": 16.0,
  "pathMaxCells": 1000000,
  "pathMaxNodes": 1000000
}
```

- `CASUAL`：休闲模式。默认开配平、高度保持，巡航默认关闭；碰撞伤害较低、预转 5 秒，尾桨失效不施加反扭矩惩罚。允许一键起降。
- `MAMBA`：**曼巴模式**。辅助默认关闭但可手动启用，允许导航自动驾驶；惯性更强、预转 12 秒、油耗更高、尾桨失效惩罚严格，迫降容错更低。禁用一键起降。
- `ZOBAYAN`：**佐巴扬模式**。沿用曼巴物理，配平、高度保持、巡航、导航自动驾驶及一键起降全部禁用；正常带转速飞行也持续损耗机身、旋翼、尾桨，尤其引擎（满转速且持续满足磨损条件时约 2.4 耐久/分钟）。地面不施加该飞行磨损，离机也不提供三秒辅助悬停。
- `explosionBlockDamage=false`：关闭爆炸方块破坏与点火，仍保留载具事故、爆炸实体伤害和乘员致命伤害。
- `wind=false`：关闭风扰动；雨天功率和旋翼效率衰减仍存在。
- `rotorPreSpin=false`：跳过预转等待，依然需要启动引擎并增加总距。
- `fuelCapacity`：100–30000；`explosionPower`：0–12。异常参数会被限制到有效范围。
- 自动驾驶规划配置由服务器统一管理，手动修改后重启世界/服务器；非法非有限数恢复默认值，越界值限制到有效范围并在日志中说明。

| 规划配置 | 默认值 | 允许范围 / 作用 |
|---|---:|---|
| `autopilotCruiseKmh` | 75 | 20–80 km/h，按 20 TPS 换算的巡航目标 |
| `autopilotLookMin` | 8 | 4–16 格，低速前视距离 |
| `autopilotLookMax` | 30 | 最小前视距离–48 格，高速前视上限 |
| `gridCellSize` | 2 | 0.25–64 格；减小可表示更窄通道，但增加网格与搜索成本 |
| `pathSafetyMargin` | 2 | 0–1024 格；在飞机自身规划半径之外增加的禁飞区安全余量 |
| `pathBoundaryMargin` | 16 | 1–4096 格；包围起终点及所有扩张禁飞圆后额外保留的边界空间 |
| `pathMaxCells` | 1000000 | 1–2000000；单次规划可分配的网格数上限 |
| `pathMaxNodes` | 1000000 | 1–2000000；单次规划 A* 可访问节点数上限 |

增加预算不能解决处于真实禁飞圆内的起终点，也不会让被禁飞圆真正封闭的不同区域连通。全维度相距很远的雷达会扩大动态规划矩形，可能触发网格预算；这种情况会报告资源限制，不截断禁飞区数据或假称无路。
