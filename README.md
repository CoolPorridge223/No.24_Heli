# 24号直升机 / No.24 Heli

Minecraft 1.21.1 · Fabric Loader 0.19.2 · Fabric API 0.116.17+1.21.1 · Java 21 及以上。

## 安装

将 `build/libs/No.24_Heli-1.2.1.jar` 放入游戏实例的 `mods` 文件夹，同时安装匹配的 Fabric API。联机时客户端和服务器都要更新到 1.2.1。本模组不需要额外动画库，MP3 解码库已内置。不要安装带 `-sources` 的源码包。

## 第一次飞行

1. 在空旷位置右键方块放置“24号直升机”，机头朝向与你一致。主旋翼周围留出至少 4 格空间。
2. 手持任意普通物品（例如煤油）蹲下右键机身打开燃油/货仓；将煤油放入左上燃料槽。落地时每秒消耗 1 份补给，煤油补充 150 单位，原油补充 80 单位。新造飞机没有燃油。
3. 空手右键登机，自动切换到拉远的第三人称并隐藏机内乘员模型。第一位为驾驶员，第二位为副驾驶。按 **R** 启动，等旋翼达到 100%：休闲模式约 5 秒，曼巴模式约 12 秒。
4. 按住 **空格** 逐渐增加总距；约 56% 是完好、水平、晴天的悬停起点。转速未满时抬总距也无法离地。起飞后通过 H 保持高度，W 推杆前飞。
5. 降落时松开巡航，S 拉杆减速、J 配平、G 放下起落架，再用左 Ctrl 减小总距缓降。接地后将总距降到 0，再按 R 关闭引擎，等待旋翼停转。

**R 在空中也能切断动力，会进入无动力自转下降，不能当作普通降落按钮。** 旋翼需要时间停转，地面大修与涂装须等待完全停转。

## 操作表

除鼠标飞控、Q/E 和左 Ctrl 外，专用按键可在游戏“选项 → 控制 → 按键绑定 → 24号直升机”调整。Q/E 与原版丢弃/背包默认键重叠，驾驶时由模组接管；其他按键冲突也可在此修改。

| 输入 | 功能 |
|---|---|
| W / S | 低头前飞 / 抬头减速，保留惯性 |
| A / D | 左右侧倾与侧滑 |
| 鼠标上下 / 左右移动 | 离地后控制俯仰 / 横滚；N 切换鼠标操纵与自由观察 |
| 鼠标中键（可重绑） | 视角锁定，平滑跟随机头方向；再次点击取消 |
| 空格 / 左 Ctrl | 增加 / 减小总距；松手保持当前总距 |
| Q / E（或可重绑的 Z / V） | 左右脚蹬，控制偏航与手动抗扭 |
| R | 引擎启停；两次切换之间至少 1 秒 |
| H | 高度保持；手动改总距时重新记录目标高度 |
| J | 自动配平；关掉后松杆会保留机身姿态 |
| I | 巡航保持当前空速；手动前后操纵更新目标速度 |
| G | 收放起落架 |
| B | 悬停时部署/收回绳索 |
| Y | 机内沿绳下机；地面靠近空闲绳端时抓绳自动攀升 |
| O | 打开燃油/货仓界面 |
| M | 乘机时打开 / 关闭导航地图；Esc 也可返回，未登机不能打开 |
| N | 切换鼠标操纵 / 自由观察 |
| U | 开启 / 关闭自动驾驶；需要导航点且离地至少 10 格 |
| K | 休闲模式一键起飞 / 降落；再次按下取消 |
| 按住 Tab | 打开八槽电台圆盘，移动鼠标选曲，松手确认；中心为关台，Esc 取消 |
| 鼠标滚轮 | 第三人称乘机时调整相机距离；地图内缩放地图 |
| Shift | 地面/水中立即下机；空中首次警告，松开后 3 秒内再次按下确认。绳上离地 ≤3 格直接脱离，>3 格也须两次确认 |
| 绳上空格 / 左 Ctrl | 切换为向上攀升 / 向下绳降，松手继续当前方向 |

登机隐藏快捷物品栏（货仓 O 仍可使用），下机恢复。相机初始距离为 10 格，可用滚轮在 4–24 格之间调整，遇到墙壁自动缩短以避免穿墙；F5 仍可切换视角，下机恢复登机前的视角。“视角锁定 / 取消”默认中键，可在原版控制菜单改为键盘或其他鼠标键；N 单独控制鼠标是否参与飞控。旧版默认 K 会一次性迁移到 J；其他自定义绑定保持原值。旧版默认鼠标操纵切换 M 一次性迁移到 N，为地图让出 M。

驾驶员空中离机后，飞机先尝试稳定悬停约 3 秒，再逐渐倾斜、自旋并失去动力下坠，不会保留高总距一直爬升。重新登机可中断无人驾驶程序；若已失去动力，需要重新启动并修正姿态。严重损伤或缺油时不能保证悬停。

## 生存获取

获得铁锭后，模组合成配方会加入原版配方书。

**整机路线**：工作台按下列图案合成；I=铁块，G=玻璃，F=铁锭，C=高炉，R=红石块。

```text
I G I
F C F
I R I
```

**部件路线**：分别合成机身、旋翼总成、尾桨、引擎模块、燃油罐。将这五种物品各一份放在背包里，手持机身右键停机坪，自动检查空间并消耗材料完成组装。创造模式免材料消耗。

| 部件/补给 | 原料 |
|---|---|
| 旋翼总成 | 4 铁锭 + 1 红石，十字排列 |
| 尾桨 | 4 铁粒环绕 1 铁锭 |
| 引擎模块 | 6 铁锭 + 2 红石 + 1 熔炉 |
| 燃油罐 | 8 铁锭围成空心方框 |
| 机身 | 7 铁锭 + 1 玻璃 + 1 箱子 |
| 维修包 ×2 | 2 铁锭 + 1 铁粒 + 1 红色染料 |
| 停机坪 ×4 | 2 铁锭 + 1 黄色染料 + 3 平滑石头 |
| 原油 | 2 煤炭 + 1 玻璃瓶，无序合成 |
| 煤油 | 熔炉冶炼原油，10 秒 |
| 涂装 | 对应染料 + 铁粒 + 玻璃瓶，无序合成 |

原油采用原版材料合成，不新增矿物或世界生成。燃料为一次性补给物品，不返还玻璃瓶。

## 燃油、维护与损伤

- O 界面提供独立燃料槽和 **18 格货仓**，支持原版拖动、分堆及 Shift 快速转移。空中可使用货仓，但不能通过燃料槽空中加油。
- 停机坪上落地停机后，会自动把货仓中的煤油/原油移到燃料槽。启动自检检查燃油、引擎与主旋翼。
- 悬停较省油，高速飞行提高油耗，大幅推杆、侧滚和连续改总距会明显增加油耗。受损引擎功率下降且更耗油。
- 主旋翼、尾桨、引擎、油箱分别保存耐久，另有机身总耐久。外部攻击的方向与高度决定受损部件；机上乘员的近战和可归因的投射物不会损伤本机。创造乘员的自身飞行在机内禁用，空格仍控制直升机总距，下机后创造飞行能力保留。
- 主旋翼受损降低升力并引起抖动；曼巴模式尾桨失效会持续自旋，需 Q/E 手动抗扭。
- 油箱低于 80% 会漏油，即使停机也会继续漏。
- 地面停转时，手持维修包右键机体：各部件和机身恢复 30 点，每秒最多维修一次。驾驶中手持维修包右键可应急修复 3 点，每 10 秒一次，**不能空中补油箱**。
- 空中撞墙、撞顶仍会解体爆炸；微小接触抖动除外。与动物等非玩家实体相撞时，相对速度不超过 10 m/s（36 km/h）只伤害被撞实体，不伤害或炸毁飞机；超过门槛才按撞击强度计算机损与爆炸。玩家接触不会触发碰撞事故，地面和刚放置阶段忽略实体接触。正常低速着陆与地面低速擦碰只会按冲击扣耐久，高速撞地会爆炸并对乘员造成致命伤害。起落架收起或大倾角接地，更容易发生严重事故。
- 解体会掉落货仓物资，并留下可保存的残骸；蹲下右键残骸可回收部分铁粒，并有概率回收尾桨。

## 整机回收

所有乘员下机后，关闭引擎并等待旋翼停转，**空手蹲下右键**即可回收整机。要求机体落地停稳，或入水后速度降低；引擎完全损坏也可回收。入水会切断动力并增加阻尼，等待数秒再操作。

整机物品保存燃油、各部件及机身损伤、涂装、导航点和全部货仓。重新放置仍是原来的损伤状态，不会免费修复；运动、旋翼、引擎启停与自动驾驶重置。创造模式放置带存档的回收机也会消耗该物品，避免复制货仓。残骸仍按原方式回收零件。手持煤油等普通物品蹲下右键可打开货仓；维修包、涂装保留各自交互。

## 地图、导航与禁飞区

- **M 打开/关闭地图**：仅乘机时使用。横向长方形北向地形图采用原版地图配色与纸色边框，**左键拖动、右键设点、滚轮缩放**，Esc 返回。黄色标记为导航点，红圈为禁飞区；禁飞区内禁止设点。地图采用异步瓦片缓存和整张纹理绘制，缩小时后台逐步补齐旧地形。已接收区块自动记录到本地，离开、卸载或重进世界后仍可显示；纸色区域为尚未记录的地形。缓存从安装 1.2.1 后开始积累，不能追溯安装前已卸载的区块，也不强制加载远方世界。
- **U 自动驾驶**：驾驶员或副驾驶均可设点/清除导航点；更换导航点会取消当前自动任务。仅驾驶员可在启动、离地至少 10 格并松开操纵键后按 U 开启自动驾驶。飞机先刹住水平漂移并转向航段，持续调整机头朝向当前路线。禁飞区会触发绕行规划，途中新增或改变禁飞区会重新规划；巡航目标上限从约 27 km/h 提高至约 58 km/h，实际速度受转弯、制动、风和机况影响，接近导航点后减速悬停。任意有效方向、脚蹬、总距或鼠标飞控输入都会立即退出；引擎/飞控辅助切换同样交还控制权。N 自由观察时转动视角不算操纵。佐巴扬模式禁止自动驾驶。
- 自动驾驶会检查前方机体/旋翼净空和当前漂移方向，遇障先制动；上方及抬高后的前方有完整通道时爬升越障。未加载地形、隧道顶、世界边界或无法找到安全绕行路线时制动等待，不强行穿越。它不自动起降，严重损伤或动力不足仍可能失高；落地、入水、失去驾驶员或动力会退出，存档重载后须手动重新开启。禁飞区路径预留安全间距，贴近禁飞边界的导航点可能无法建立安全路线。
- **禁飞区雷达**：用 3 铁锭、1 指南针、1 红石合成（上排中间铁锭，中排“铁锭/指南针/铁锭”，下排中间红石），放置后默认建立半径 64 格禁飞区。右键打开设置，可输入 **16–512 格**；仅放置者或管理员能修改。
- 禁飞区为全高度圆柱，仅在所在维度生效。区块卸载不会关闭禁飞区，破坏雷达会删除该区；每维度最多 512 个。飞机进入后，乘员会收到文字和周期声音警报。禁飞区目前只告警，不强制击落或阻挡飞机。

## 一键起降与机载电台

**休闲模式按 K**：地面自动启动、预转并爬升约 10 格，完成后保持高度；空中自动减速并垂直降落，真正接地后关闭引擎。头顶需有完整起飞空间，降落点中心和四角需是干燥、接近同高的支撑面，飞机还需有燃油及足够的引擎/旋翼耐久。再次按 K 或主动操纵会接管取消。它不具备自动避障能力，曼巴和佐巴扬模式均不能使用。

电台仅预留 **8 个槽位，不内置音乐**，文件依次命名为 `slot_1.mp3` 至 `slot_8.mp3`。**单人游戏放在本地游戏实例的 `config/no_24_heli_radio/`；多人游戏由服主放在服务器的同名目录**。局域网开放世界由房主提供文件。多人客户端无需自行放歌，也不会使用自己目录中的同名文件替代服务器歌曲。不必填满，空槽位显示“空”。

驾驶员和副驾驶均可按住 Tab、移动鼠标选择槽位后松手播放，选圆盘中心停止。多人首次听到某首歌时自动从服务器后台分片获取，不向玩家显示正在加载音乐的提示，完成校验后按当前进度播放；同一次连接内后续使用缓存，无需重复下载。服务器单曲上限 **32 MiB**，添加或更换歌曲后重启服务器/局域网世界以刷新目录。单人新增文件后重新打开圆盘即可看到，替换当前歌曲后先关台再重选。音乐来源统一为 config，不再使用资源包歌曲后备。

音乐循环播放，后来靠近的玩家从对应进度接入。机内音量不受第三人称镜头远近影响，其他玩家按自身到飞机的距离衰减，64 格外无声；受游戏“唱片机/音符盒”和主音量控制。禁飞警报也不再随镜头拉远而变小。多人下载缓存位于客户端 `config/no_24_heli_radio_cache/`，退出世界、断开服务器或正常关闭游戏时自动清除，下次进入后按需重新获取；自己的 `config/no_24_heli_radio/` 原始音乐不会删除。客户端与服务端均需替换为本次修订包，版本号仍为 **1.2.1**。

## 自转迫降

动力丢失后，先降低总距，让下降气流维持旋翼转速；保持机身接近水平和适当的前飞速度。接近地面时拉杆减速并逐渐增加总距，利用旋翼储存的能量减小接地速度。过早大总距会耗尽旋翼能量，过晚拉平会高速撞地。优先放下起落架，避开建筑、水面和陡坡。

这是面向游戏的简化直升机物理，不是现实航空训练程序。高度表是世界 Y 坐标；垂直速度单位为 m/s，空速按 1 格≈1 米换算显示为 km/h。

## 乘员、绳降与涂装

驾驶员先登机，再让第二位玩家右键登机。可用拴绳将附近 5 格内未乘坐载具的村民装入空余座位。村民无法驾驶。请由驾驶员登机后手持拴绳右键装载村民。

放绳要求直升机距下方地面 **大于 3 格、不超过 24 格**、水平速度低于 2 m/s、垂速绝对值低于 1.5 m/s。驾驶员按 B 部署，机内玩家按 Y 下绳；副驾驶座的村民在部署时自动下绳。每根绳子一次承载一人；绳上有人时不能收绳，并可携带悬挂人员飞行。空绳在脱离稳定悬停后自动收回。

地面玩家靠近空闲绳端（约 3 格内）按 **Y** 自动攀升；空格切换向上，左 Ctrl 切换向下。攀升速度约 2.8 m/s、绳降约 4.6 m/s。到顶有空座自动进入驾驶舱，满员时继续挂在机腹下方，随飞机运动保留惯性摆动；座位腾出后自动入舱。绳端按实际连接位置独立绘制，机身离开视野也能看见绳段。

绳上按 **Shift** 可主动脱离：离地不超过 3 格时立即释放；超过 3 格时，先警告，松开后须在 3 秒内再次按下确认。主动高空脱离后正常承担后续坠落风险；沿绳到达地面会自动安全解绳。

绿色、白色、黄色、黑色、橙色染料分别合成丛林、雪地、沙漠、纯黑、救援橙涂装。新增**紫金24号涂装**：紫色染料 + 黄色染料 + 铁粒 + 玻璃瓶，无序合成；紫色机身、金色饰带，机身左右两侧都有金色“24”。落地并等待旋翼停转后，手持涂装右键机身。涂装只改变外观。

## 难度与配置

在游戏“选项”中打开 **直升机设置**。**我的飞行模式**由每名玩家独立选择，普通玩家也能修改，按 UUID 保存在当前服务器存档中，跨维度、重登及重启保留。飞机按当前驾驶员的模式运行；副驾驶修改自己的模式不影响本机，接任驾驶后才生效。无人驾驶时沿用最后模式。

**全服爆炸破坏 / 着火**仍由房主或具有 2 级权限的管理员统一修改，普通玩家只能查看。关闭后不破坏方块、不点火，但事故爆炸及乘员致命伤害仍存在。

个人模式切换无需重启，仅重置自己正在驾驶的飞机的辅助并取消自动任务；燃油、部件耐久、速度和总距保留。切回休闲默认打开配平与高度保持，**巡航在所有模式下都默认关闭**。

HUD 最左下角为燃油、旋翼转速、总距三个表盘，上方为机身模式与自动控制状态，机组占位框位于这些信息上方。底部五段耐久条无间隙拼接且进一步缩短。右下从右向左为空速表盘、上下移动的垂速竖条、高度与垂速两行数字；高度使用世界 Y 坐标，垂速为正向上、负向下、零在竖条中心。

飞行时按实际离地距离触发 **30 / 20 / 10 / 5 米**近地提示，音量、音高和重复频率逐级增强；接地、入水、未起飞和离机后不播放该提示。近地距离与 HUD 的世界高度是不同读数。

右上机载雷达半径为 **512 米**，机头方向为上，白色指针为本机，蓝点为玩家、橙点为完好飞机、金色菱形为导航点，红色弧线为禁飞区边界；超出 512 米的导航点钳在外圈指示方向。服务器每半秒提供同维度已加载目标的坐标快照，因此超出客户端完整实体跟踪距离的目标也可显示；不会为扫描强制加载远方区块，最多显示距离最近的 512 个目标。

视角锁定绑定仅在乘机且未打开界面时生效；离机后同键的原版操作保留。雷达方块使用非整块遮挡形状，底部不再使下方地形透视。

首次运行后生成 `config/no_24_heli.json`。其中 `difficulty` 仅作为尚未设置个人模式的默认值。手动修改文件后重启世界/服务器，联机以服务端配置为准。主菜单中的设置编辑本地默认值。

```json
{
  "difficulty": "CASUAL",
  "explosionBlockDamage": true,
  "wind": true,
  "rotorPreSpin": true,
  "fuelCapacity": 1200.0,
  "explosionPower": 5.0
}
```

- `CASUAL`：休闲模式。默认开配平、高度保持，巡航默认关闭；碰撞伤害较低、预转 5 秒，尾桨失效不施加反扭矩惩罚。允许一键起降。
- `MAMBA`：**曼巴模式**。辅助默认关闭但可手动启用，允许导航自动驾驶；惯性更强、预转 12 秒、油耗更高、尾桨失效惩罚严格，迫降容错更低。禁用一键起降。
- `ZOBAYAN`：**佐巴扬模式**。沿用曼巴物理，配平、高度保持、巡航、导航自动驾驶及一键起降全部禁用；正常带转速飞行也持续损耗机身、旋翼、尾桨，尤其引擎（满转速且持续满足磨损条件时约 2.4 耐久/分钟）。地面不施加该飞行磨损，离机也不提供三秒辅助悬停。
- `explosionBlockDamage=false`：关闭爆炸方块破坏与点火，仍保留载具事故、爆炸实体伤害和乘员致命伤害。
- `wind=false`：关闭风扰动；雨天功率和旋翼效率衰减仍存在。
- `rotorPreSpin=false`：跳过预转等待，依然需要启动引擎并增加总距。
- `fuelCapacity`：100–30000；`explosionPower`：0–12。异常参数会被限制到有效范围。
