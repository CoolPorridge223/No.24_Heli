# 24号直升机 / No.24 Heli

Minecraft 1.21.1 · Fabric Loader 0.19.2 · Fabric API 0.116.17+1.21.1 · Java 21 及以上。

## 安装

将 `build/libs/No.24_Heli-2.4.3.jar` 放入游戏实例的 `mods` 文件夹，同时安装匹配的 Fabric API。联机时客户端和服务器都要更新到 2.4.3。本模组不需要额外动画库，MP3 解码库已内置。不要安装带 `-sources` 的源码包；同一游戏实例只安装一个版本的本模组，保留的旧 JAR 放在备份位置。

## 第一次飞行

1. 在空旷位置右键方块放置“24号直升机”，机头朝向与你一致。放置时起落架完全放下，点击顶部按实际表面高度生成，支持薄停机坪。主旋翼周围留出至少 4 格空间。
2. 手持任意普通物品（例如煤油）蹲下右键机身打开燃油/货仓；将煤油放入左上燃料槽。落地时每秒消耗 1 份补给，煤油补充 150 单位，原油补充 80 单位。新造飞机没有燃油。
3. 靠近希望进入的舱门，按 **F** 或右键机身，自动开门进入最近舱门对应的座位，坐稳后关门。左前门为主驾、右前门为副驾，左右后门各对应一个后排座位；总共四座，后排没有摇杆。空座登机保留当前第一/第三人称，抬脚进入后坐下，V 可切换视角。主驾按 **R** 启动，等旋翼达到 100%：休闲模式约 5 秒，曼巴模式约 12 秒。
4. 按住 **空格** 逐渐增加总距；约 56% 是完好、水平、晴天的悬停起点。转速未满时抬总距也无法离地。起飞后通过 H 保持高度，W 推杆前飞。
5. 降落时松开巡航，S 拉杆减速、J 配平、G 放下起落架，再用左 Ctrl 减小总距缓降。接地后将总距降到 0，再按 R 关闭引擎，等待旋翼停转。

**R 在空中也能切断动力，会进入无动力自转下降，不能当作普通降落按钮。** 旋翼需要时间停转，地面大修与涂装须等待完全停转。

机身左右各有前后两扇门，像轿车一样绕各自前缘铰链向外打开，玻璃、内饰和涂装跟随门体转动。机外 F 或右键串联开门、登机和关门；机内 **Shift 或 F** 串联开门和下机，地面、水中和空中离机后都会自动关闭对应舱门。空中首次按键立即提示危险，松开后 3 秒内再次按 Shift 或 F 才开门并跃出。动作期间重复按键不会打断乘降；地面或水中出口被地形或实体卡住时不再播放开门和下机动画，直接按原版方式下载具离开，优先落到另一侧可站立点，实在没有空间时落在机体顶面；只有空中找不到安全跃出位置时才提示并保留座位。屏幕中央偏右在机外显示“开门登机”，机内接地或浮水时显示“开门下机”，离地后隐藏下机提示，键名跟随重绑。空中主驾离座时，仍坐稳的副驾玩家接管主驾；后排不换座，也不能操纵飞机。

飞机在陆地停稳、最近门对应座位已坐有玩家时，按 **F** 会自动开门，将原乘员拖出，再坐入这个座位。双方动作期间临时切到面对人物正面的第三人称，新乘员坐稳后恢复原视角；原乘员趴在门外地面眩晕 **3 秒（60 个游戏 tick）**，头部周围显示眩晕星点，期间不能移动、跳跃、攻击或使用物品，随后起身并恢复视角。重复按 F 或第三人同时抢座不会重启动作；原乘员尚在上下机、飞机移动/离地/入水或门外没有落脚空间时不能拖拽。右键只进入空座，救援绳登机仍按原有后排优先规则。

登机隐藏快捷物品栏（货仓 O 仍可使用），下机恢复。机外相机初始距离为 10 格，可用滚轮在 4–24 格之间调整，遇到墙壁自动缩短以避免穿墙；V 在机内第一人称和机外后视第三人称之间切换，F5 仍可切换原版视角，下机恢复登机前的视角。“视角锁定 / 取消”默认中键，可在原版控制菜单改为键盘或其他鼠标键，第一人称禁用锁定且切入时自动解除。座舱滚轮每格改变 5°，视场角范围 25°–110°，不修改全局 FOV，下机恢复普通视野。旧版默认 K 会一次性迁移到 J；旧版右脚蹬默认 V 一次性迁移到 X，为驾驶视角切换让出 V；其他自定义绑定保持不变。

第三人称 HUD 左侧显示主驾、副驾，右侧显示后排乘客并向右对齐；两侧座位标签和姓名逐行保持同一高度。

机腹圆球为可转向探照灯，N 开关、方向键瞄准。光束默认朝前下方，从与灯头镜片同直径的圆形发光面沿云台方向展开为圆台，最远照亮 64 格内的地面与墙面，飞机移动和云台连续转动时持续照明。朝向灯头的台阶顶面和高方块侧面按实际入射方向受光，墙后的阴影沿光线延伸；箱子、床、潜影盒等通过标准模型接口绘制的方块实体也参与受光和遮挡。支持照亮另一架直升机，以及 easyelevator 的普通、高速、观光和重载移动轿厢，按实际模型、门动画与玻璃透明度计算遮挡。光线穿过打开的轿门时可照亮内壁、扶手和地板，关门后仍按实体门板遮挡。保留表面纹理、模型颜色与柔和边缘，机体会遮挡后方光斑。照明按原先两倍的暖色材质目标亮度补光，也不放大光影的太阳阴影。灯具可在自动驾驶时独立操作。红色示廓灯位于主旋翼下方两侧和尾鳍，仅引擎运行时在夜间自动闪烁，每秒亮约四分之一秒，引擎关闭、白天与残骸状态熄灭。完好机舱会局部遮挡雨雪幕，窗外降水正常显示。

机体采用圆滑机鼻、连续曲面座舱、细长尾梁、后掠尾鳍和弧形滑橇，主旋翼与尾桨均为四片有厚度的桨叶，水平尾翼与尾桨完整旋转范围保留间隙。机壳包含约 4.5 厘米的内外蒙皮、窗框断面与后隔舱，机鼻和尾部封口，尾梁与后机身共用连续截面，根部位于客舱之外。机身漆面使用 LabPBR 材质，保留板缝和铆钉；启用支持 PBR 的光影后呈现漆面反射，迷彩反射较柔和，座椅、内饰与旋翼保持哑光。玻璃采用透明中心与窗缘反光材质，保留内外厚度，透视区域不写入实体深度，兼容 iterationT 等光影的天空渲染。紫金涂装左侧保留金色“24”，右侧为同款金色渐变粗体“Laker”，其他涂装不显示文字。新造飞机默认蓝白配色，旧存档的六种涂装编号不变。

主副驾驶人物显示在各自座椅上，身体固定跟随机体倾斜，头部可有限转动观察；左驾驶席的第一人称眼位更靠前。舱顶设暖白灯，照亮内衬、座椅、乘员和面板，残骸状态熄灭。飞机启动时仪表文字与表针同步亮起，夜间开启光影也保持清晰；停机或坠毁后文字恢复环境光照。HUD 与机内圆表的指针均位于数字前方。高度和垂速表中央数字保留滚动显示并缩小留白。顶部椭球整流罩沿完整裙边接入舱顶，后方不设两根外露排气管。起落架沿机舱外向后、向上收起，支柱的机身铰点保持固定；接地后禁止收起，自动起飞离地后自动收起，向下触地时强制放下。空中放下起落架仅增加较小的水平空气阻力，每 tick 额外保留 99.5% 的水平速度。

机模保留平滑曲面法线，滑橇采用连续管面并减少隐藏端盖；纹理坐标和舱灯衰减预先缓存。24 格外停止绘制机内细节和仪表，机内第一人称仍绘制完整座舱。

主驾驶位于面向机头的左侧，副驾在右侧，第一人称眼位与实际座位同步，并随机身俯仰、横滚和偏航移动。手动和自动驾驶的偏航均使用高精度姿态快照逐帧插值，小角度转向及跨越 0/360° 时保持连续。机内面板上排从左到右是**燃油、旋翼转速、总距**，下排是**空速、垂速、高度**。HUD 和机内仪表的动力、空速、垂速、高度与姿态读数均平滑过渡，切换视角继续沿用同一架飞机的显示进度。垂速、高度沿用 HUD 的方框滚动刻度、左向指针和凸字形数字窗；高度仍为世界 Y，近地高度单独显示。姿态与雷达位于右上。机内不显示机身或部件血条；故障和自动控制改为右侧框内的图标。

右侧上框为异常：发动机、主桨、尾桨、低燃油、机舱损伤、油箱损伤、无动力自转、旋翼预转、禁飞区、下降过快、降落区域被实体占用。正常时保留暗轮廓，异常亮红色，预转亮琥珀色；降落占用灯用“下箭头、停止横线和障碍方框”表示。下框为高度保持、配平、巡航、起落架、自动驾驶、自动起飞、自动降落、导航点和探照灯，启用时亮绿色。图形含义如下：

|---|---|
| 发动机外框、四叶旋翼、尾梁带尾桨 | 发动机、主旋翼、尾桨异常 |
| 油泵、裂纹舱体、裂纹油箱 | 低燃油、机身受损、油箱受损 |
| 圆环下箭头、双圈旋翼、禁止符号、三角下箭头 | 自转、预转、禁飞区、下降过快 |
| 双竖线横杠、平衡十字、双横箭头、双轮 | 高度保持、配平、巡航、起落架 |
| 圆圈准线、跑道上/下箭头、定位钉 | 自动驾驶、自动起飞/降落、导航点 |
| 圆形灯头与三道光线 | 探照灯；开启时为绿色，关闭时保留暗轮廓 |

第一人称隐藏屏幕飞行 HUD、准星、原版状态条和手持物；聊天、交互消息、货仓和地图仍可使用。鼠标始终自由观察座舱，滚轮缩放视野，不能锁定机头；第三人称仍保留原有屏幕 HUD 和底部耐久条。


驾驶员空中离机后，飞机先尝试稳定悬停约 3 秒，再逐渐倾斜、自旋并失去动力下坠，不会保留高总距一直爬升。重新登机可中断无人驾驶程序；若已失去动力，需要重新启动并修正姿态。严重损伤或缺油时不能保证悬停。

## 应急跳伞

将“滑翔伞包”放入**胸甲槽**，或手持伞包右键穿戴。它与胸甲、鞘翅共用槽位，不提供护甲。驾驶员和副驾各自穿戴、独立操纵；飞机故障时按 Shift 或 F 立即收到空中危险提示，松开后 3 秒内再次按任一下机键，自动开门并跃出。离地**至少 10 格**时，在屏幕中央偏右显示金色的“按下 F 展开降落伞”；不足 10 格时不显示，也无法开伞，没有额外警告。离机继承飞机速度并带侧向跳跃冲量，离舱后按 F 后经历拉绳、张翼和充气，约 **1.2 秒**完成展开，并更快建立减速。

穿戴已叠好的伞包，且离地**严格超过 50 格**时，跃出后才从离舱动作平滑转为趴姿飞行；普通高处下落超过两格时也需满足同一高度条件。地面、平台和水面均计入离地高度，正好 50 格不会触发；较低处保持普通下落，仍可在满足原有 10 格门槛及净空时直接开伞。鼠标改变身体朝向，**WASD 控制相对朝向的水平平移**，速度约 17 m/s，人物向移动方向倾斜，碰撞体积同步随身体俯仰、横滚和转向。张开姿态有较大空气阻力，稳定下降约 18.4 m/s；只有按 W 纯向前平移收拢四肢时减小阻力，低头越多，下降越快，最高为原版自由落体终端速度约 78.4 m/s。水平观察至抬头看天阻力相同，不产生升力；不按 W 时低头也不会增加下降速度。松键、后退、左右及斜向平移时双手双脚张开，并逐渐减速回张开姿态的下降速度；只有纯向前平移时双腿并拢、双手贴身，切换动作平滑过渡。按 F 开伞后保留原速度，身体逐渐起身、伸手握住吊绳，第一/第三人称与衣物层共用动作。跳伞和开伞后不弹出操作说明。未开伞触地仍正常承担跌落伤害，结束后恢复普通移动与视角；伞包在真正展开前保持已折叠状态且不消耗耐久。

联机时，客户端和服务器须同时安装包含伞包的同一构建。

伞包在手持、背包和掉落时按实际状态显示三种独立模型：**完好**为扣紧的完整背包，**尚未折叠**为打开翻盖、露出伞布和绳索，**损坏**为破裂包体和断带。它们沿用同一伞包的耐久、附魔与折叠状态；叠伞后外观自动恢复完整，永久损坏不会因换模型而恢复可用。

展开后是带弧形翼面、气室、吊绳和布面起伏的滑翔伞。左右各有**三组吊绳，每组两根**，十二个吊点覆盖四个角和前后翼缘；两侧各自汇束后，由两股粗主绳沿肩部延伸进背包。汇束处分别垂下一个黄色操纵拉手，人物双手握住拉手，第一人称也显示对应手臂。**W 时双手向前拽拉手，人物和伞一起前倾；S 时向后拉，一起后倾**；A 左转左倾并将左拉手拉得更低，D 右转右倾并将右拉手拉得更低。人物整体始终随伞一起旋转、倾斜，第三人称双腿自然悬垂并略有摆动，镜头仍可自由观察，落地离伞后恢复原版动作。W 增加前进速度，S 逐渐制动并进入缓慢后退。输入和速度都有明显阻尼，松键不会立即停住。中性晴天滑翔约前进 6.8 m/s、下沉 2.6 m/s；持续深制动或转弯会增加下沉，伞没有动力，不能悬停或爬升。F5 可查看第三人称，乘伞时相机拉至 8 格并保留墙壁遮挡检测。

周围必须容得下完整伞翼，墙边、狭窄空间或顶板下方不能开伞，也不显示 F。正常接地、入水或撞墙会结束伞降并取消气动减速，空中撞墙后恢复正常下落。伞面不会立即消失，会失压落地并被吊绳拖行，直到从胸甲槽取下原伞包。每次展开后都必须叠伞：手持使用过的伞包，连续按住右键 **5 秒**，屏幕中央显示圆圈进度和“正在叠伞”；松手、切换物品均重新计时。未叠好的伞包不能重新放入胸甲槽，修复耐久也不能代替叠伞。

落地伞面保留软厚度，通常落在人物附近约 **2–4 格**，实际距离随惯性、地形和绳子松紧变化。十二根独立柔绳有分段物理节点，会松弛、落地和折弯，只有绷紧时才拉动对应的布面吊点；绳根跟随背包和身体航向，玩家靠近伞面不会把整张伞推开。伞面显示细分为 **48×16 段**，拖拽时吊点先动、两翼滞后，整张布能在地面内弯成连续弧线，并随地形起伏；弯曲韧性限制锐折和严重重叠。伞布保留防撕裂织纹，两端为紫色，主翼为橙色，中心为米白色。布料与软绳都有体积碰撞和穿入恢复。

伞布上下层使用相同的三角拆分并分别计算平滑法线，保持扭曲布面的厚度与光照连续。拖行布面和柔绳在客户端逐帧平滑追踪服务端快照，新快照从当前显示位置继续过渡。

空中伞顶距人物脚底约 **5.2 格**，翼尖向下弯曲约 **1.6 格**，人伞之间保留更宽的吊绳空间。

伞包耐久为 **256**，展开消耗 4 点，飞行中每 5 秒消耗 1 点，支持原版耐久 I–III 和经验修补。背包 2×2 或工作台 3×3 合成格中放入一只受损伞包和皮革即可修复；每格皮革消耗一张、恢复 **64 点**，多格累加，保留附魔和折叠状态。铁砧也支持皮革修复。

剩余耐久**低于 10%** 时，每次开伞有 **10%** 概率故障：其中 60% 为展开卡住、没有减速，需快速连续点击 F 拉绳直至完成；30% 为伞面撕裂，气动减速效果减半；10% 为展开后伞面脱落，伞面随风飘落并在约 15 秒后消失，玩家恢复快速坠落。最后一种会永久损坏伞包，无法叠伞、皮革修复或经验修补。

开伞需要减速距离，过低或过晚开伞仍可能受到致命撞击；卸下伞包会失去伞翼并继续下落，耐久耗尽也会失去保护。飞机爆炸时仍留在舱内的事故规则保持原样，必须及时离舱。

## 生存获取

常用部件在获得铁锭后加入原版配方书；伞包在获得皮革后解锁。

**零件组装**：生存模式制造新直升机必须通过零件组装，整机不能在工作台直接合成。分别合成机身、旋翼总成、尾桨、引擎模块、燃油罐，将这五种物品各一份放在背包里，手持机身右键停机坪，自动检查空间并消耗材料完成组装。创造模式免材料消耗。停机坪为直径 **10 格**、厚 **0.25 格**的圆盘，中间有白色大 H 与黄色边环。黄色边环内均匀布置 **16 盏暖黄色指示灯**，灯体不超出边线，白天自动熄灭、夜晚自动开启。停机坪底座和标记均不自发光，亮度随环境光照变化。放置时整个圆盘范围需要空闲，且不得与禁飞区相交或相切；拒绝放置时不消耗物品。只消耗一个物品，任意位置右键机身都在中心组装，停机补给在整个平台上有效。破坏任意一处拆除整个圆盘，只掉落一个停机坪。旧存档的单块停机坪请拆下后在空地重新放置。

## 燃油、维护与损伤

- O 界面提供独立燃料槽和 **18 格货仓**，支持原版拖动、分堆及 Shift 快速转移。空中可使用货仓，但不能通过燃料槽空中加油。
- 停机坪上落地停机后，会自动把货仓中的煤油/原油移到燃料槽。启动自检检查燃油、引擎与主旋翼。
- 悬停较省油，高速飞行提高油耗，大幅推杆、侧滚和连续改总距会明显增加油耗。受损引擎功率下降且更耗油。
- 主旋翼、尾桨、引擎、油箱分别保存耐久，另有机身总耐久。机舱、动力罩、油箱、尾梁/尾翼、尾桨、主旋翼和滑橇具有随偏航、俯仰及横滚旋转的分部碰撞体；近战、原版箭矢和碰撞按实际接触部位结算。尾桨受撞优先损伤尾部，不再误扣引擎或主旋翼。机上乘员的近战和可归因的投射物不会损伤本机。创造乘员的自身飞行在机内禁用，空格仍控制直升机总距，下机后创造飞行能力保留。
- 主旋翼受损降低升力并引起抖动；曼巴模式尾桨失效会持续自旋，需 Q/E 手动抗扭。
- 油箱低于 80% 会漏油，即使停机也会继续漏。
- 地面停转时，手持维修包右键机体：各部件和机身恢复 30 点，每秒最多维修一次。驾驶中手持维修包右键可应急修复 3 点，每 10 秒一次，**不能空中补油箱**。
- 主旋翼和发动机损伤叠加雨天影响，可能使满转、最大总距也无法起飞。升力不足时，HUD 与机内仪表持续提示“可能无法起飞”，R 启动时也会提醒；维修或天气变化后自动解除。自动起降因主旋翼耐久低于 70% 或升力不足被拒绝时，会明确说明原因。
- 平移碰撞连续检测整段位移，原地转向也检查尾部扫过的区域；两架飞机按双方真实分部盒阻挡。机舱、引擎、油箱、尾梁或起落架的高速撞击均可能解体爆炸，包含垂直撞顶和坠地；伤害间隔不能免除高速事故。机体结构或滑橇接地时，合成倾斜超过 **30°** 会直接坠毁爆炸，弃机同样适用。主旋翼转速达到额定的 **50%** 时撞方块一次扣光旋翼耐久，低转速按转速与撞击强度扣耐久，单纯旋翼接触不直接引爆整机；折断后的桨盘不再挡住机身后续撞击。旋翼碰到外部玩家、动物等实体时降低耐久并伤害对方，不按方块规则瞬间折断。同机乘员、旁观者及救援绳乘员排除，刚离机的乘员在两秒内不会与原飞机发生碰撞事故；机身与实体的相对速度不超过 10 m/s（36 km/h）时不反伤本机。正常水平低速着陆和静止贴地重力不扣耐久。
- **F3+B** 可查看随飞机旋转的分部线框：白色机舱、橙色引擎、黄色油箱、青色尾梁/尾翼、紫色尾桨、红色主旋翼、绿色滑橇。停转时显示四片桨叶与桨毂，运转时显示分段扫掠桨盘。
- 解体会掉落货仓物资，并留下可保存的残骸。残骸接地后按机舱重心继续倾倒、沉降，直到获得稳定支撑；尾部先触地时也会继续倒下，侧卧姿态可正常保存。蹲下右键残骸可回收部分铁粒，并有概率回收尾桨。

## 整机回收

所有乘员下机后，关闭引擎并等待旋翼停转，**空手蹲下右键**即可回收整机。要求机体落地停稳，或入水后速度降低；引擎完全损坏也可回收。入水会切断动力并增加阻尼，等待数秒再操作。

整机物品保存燃油、各部件及机身损伤、涂装、导航点和全部货仓。重新放置仍是原来的损伤状态，不会免费修复；运动、旋翼、引擎启停与自动驾驶重置。创造模式放置带存档的回收机也会消耗该物品，避免复制货仓。残骸仍按原方式回收零件。手持煤油等普通物品蹲下右键可打开货仓；维修包、涂装保留各自交互。

## 地图、导航与禁飞区

- **M 打开/关闭地图**：仅乘机时使用。横向长方形北向地形图采用原版地图配色与纸色边框，**左键拖动、右键设点、滚轮缩放**，Esc 返回。黄色标记为导航点，红圈为禁飞区；禁飞区内禁止设点。地图使用 GPU 绘制分块纹理，按区块增量更新；拖动、缩放复用缓存，飞行时优先更新附近新地形，缩小时后台逐步补齐旧地形。已接收区块自动记录到本地，离开、卸载或重进世界后仍可显示；纸色区域为尚未记录的地形。缓存从该客户端开始记录地形时积累，不能追溯记录前已卸载的区块，也不强制加载远方世界。
- 地图上的白色无柄导航箭头表示自己乘坐的飞机，橙色小一号箭头表示其他飞机，尖端与机头方向一致。停机坪是地图上的**固定圆形 H 标记**，H 按可见笔画居中且无阴影；离开雷达范围、卸载区块或重进世界后仍保留；实际拆除时移除。**直接点击圆形 H 即可设为导航点**。旧停机坪被禁飞区覆盖时显示红色圆形 H，无法设置导航；普通右键设点同样不能绕过该限制。旧存档中尚未登记的停机坪在所在区块首次加载时自动加入目录。机载雷达使用独立扫描结果，只显示 **512 格内已加载的停机坪**，超出范围后从雷达消失。更新此功能时客户端和服务端须一起替换 JAR。
- **U 自动驾驶**：驾驶员或副驾驶均可设点/清除导航点；更换导航点会取消当前自动任务，需再次按 U 规划。仅驾驶员可在启动、离地至少 10 格并松开操纵键后按 U 开启自动驾驶。首次规划时先制动，生成禁飞区引导路线并主动加载航路所需区块；飞行期间提前计算后续三维航段，连续交接，普通中间航点无需停车。默认巡航目标 **75 km/h**，可配置至 **80 km/h**；转弯采用经过整机净空验证的圆角轨迹，并按曲率和升降能力提前限速。接近最终导航点时，按真实水平距离、制动能力和姿态响应时间提前减速，低速停稳后退出并保持悬停。短暂障碍先减速等候，持续堵塞或禁飞区变化时重新规划。山谷连续升降时按当前安全前视点调节高度，到达山脊或谷底附近后才转入反向升降；绕禁飞区中途重规划保留尚未抵达的绕行目标。实际速度受转弯、制动、风、机况及服务器 TPS 影响。任意有效方向、脚蹬、总距或鼠标飞控输入都会立即退出；引擎/飞控辅助切换同样交还控制权。N 自由观察时转动视角不算操纵。佐巴扬模式禁止自动驾驶。
- 导航采用 **禁飞区八邻接 A* 引导 + 地形二十六邻接三维加权 A***。露天直达走廊验证通过即可飞行，遇障碍再扩大范围比较左绕、右绕、爬升、下降和升降后侧绕；搜索计入跨格缓坡中前进与升降同时进行的时间收益，估算代价相同时优先保持原高度。三维搜索使用 4 格体素，并把旋翼、尾梁和转向所需的整机包络计入净空；每个航段、斜向跨格、圆角曲线和实际惯性通道均须安全，实际运动仍使用原飞行物理和碰撞系统。
- 起点或终点位于真实禁飞圆内或边界上时拒绝规划；需要先手动驶离或更换导航点。两点相同且合法时直接报告已到达。区域被禁飞圆围住并不自动判为不可达：同一封闭区域内仍允许导航，只有确实不连通才报告封闭原因。二维与三维规划统一使用至少 8 格的整机安全净距；真实目标仍在净距内时不会勉强飞入。满足净距的贴边目标可通过安全连接段接入邻近格心，三维禁飞圆按完整线段精确检查，避免体素额外扩大禁区。二维禁区引导中，合法坐标无法安全接入或窄通道无法表示时，会有限细化网格（最多三轮，最细 0.25 格）；仍未解决则提示精度或资源限制，不能当作物理上无路。网格、搜索节点或几何运算超过预算时明确报告资源限制，飞机制动悬停；可主动接管、修改配置或更换导航点。
- **穿洞仅作为高风险备选**：经过顶棚的航段水平速度最多 18 km/h，洞内时间按三倍计入比较，每次进入再加 20 秒等效风险代价；寻路和平滑均计入整段限速。只有从入口、内部到已确认露天出口全程均容得下整机，才可能采用。入口大但中途变窄、出口未知或仍在顶棚下的路线不采用。包络与体素会保守拒绝部分实际能勉强通过的洞，不承诺贴壁飞行。
- 地形规划每次采集最多前视 512 格，并提前加载和计算续段，导航总距离不受玩家当前区块加载范围限制。直达探测优先采集中心线周围 16 格走廊；遇障碍后向起终点矩形四侧各扩展 96 格，体素预算不足时缩短单次采集范围。区块生成和采集分摊到多 tick；取消、到达或飞机移除时释放临时加载票，已飞过的区域也会逐步释放。新区块生成较慢或确实无安全续段时仍会在已验证航路末端减速等待，允许上下选择航路但不自动降落。有限范围、加权搜索和四格分辨率不保证全局最短时间。手动接管方式不变；落地、入水、失去驾驶员或动力会退出，存档重载后须重新开启。
- **禁飞区雷达**：用 3 铁锭、1 指南针、1 红石合成（上排中间铁锭，中排“铁锭/指南针/铁锭”，下排中间红石），放置后默认建立半径 64 格禁飞区。右键打开设置，可输入 **16–512 格**；仅放置者或管理员能修改。
- 禁飞区为全高度圆柱，仅在所在维度生效。区块卸载不会关闭禁飞区，破坏雷达会删除该区；不再设置每维度固定的禁飞区数量上限，规划仍受网格及运算预算限制，网络快照受游戏数据包大小限制。飞机进入后，乘员会收到文字和周期声音警报。禁飞区目前只告警，不强制击落或阻挡手动飞行。

- 前方区块尚未加载时，自动驾驶会主动请求加载并制动等待，不把加载慢当作航线堵塞。地形安全规划失败后保留加载票据，等待所需区块全部加载且距离失败至少 5 秒后重新采集，最多重试两次；成功后继续导航，两次仍失败则在安全航段末端悬停并提示，可调整导航点、重新开启导航或手动接管。

- 近距离前视目标采用航向滞回，升降段附近不会因微小漂移反复左右掉头；允许在安全通道内低速转向并前进。通道畅通但连续约 12 秒无有效航路进展时，从当前机位重新规划，同处最多两次；仍无法前进则制动悬停并提示接管，不会无限重试。正常升降计入进展，等待区块不计入卡滞。

- 已就绪航段之间的前视和洞内限速由两段地形快照联合检查，直线接缝保持连续巡航，不因离开旧快照范围而缩短前视、减速点头。真正的转弯、障碍、最终到点及续段未就绪仍按需要减速。

## 一键起降与机载电台

救援绳挂载的玩家越多，摆动衰减越强，同时保留飞行带来的惯性。向上攀爬会在机腹下方留出头顶空间；到达安全攀爬上限下方 **半格以内**、副驾空闲时，屏幕中央偏右显示“按下 E 进入飞机”，其中 E 带圆角方形键帽。提示由服务器确认，松开 W 后单独按 E 即可入座。

飞行过程中，挂绳玩家撞墙或被方块卡住时会立即脱绳，停在碰撞限制的位置，并按运动速度承受撞击伤害；速度越快伤害越高，严重时可以致命，脱绳后照常下落。绳索不会为了拖拽受阻玩家而无限拉长。

**休闲模式按 K**：地面自动启动、预转并爬升约 20 格，完成后保持高度；空中先减速、回正并对准降落位置再垂直下降，真正接地后关闭引擎。启动前检查完整 20 格升空通道，爬升期间持续复核剩余上方空间；途中出现方块或实体阻挡会直接结束自动起飞、制止继续上冲并在当前位置保持高度，清除障碍后也不会自行重启。降落分别检查**滑橇支撑**与**机体净空**：两条滑橇前后的承重区域必须干燥、连续、同高；机身、转动主旋翼、长尾与尾桨按各自实际范围检查完整下降通道，并保留少量安全余量。桨盘和尾梁下面允许悬空、凹地或不接触机体的低矮物体，无需把整个外接矩形铺平；薄停机坪按真实碰撞顶面判断。飞机还需有燃油及足够的引擎/旋翼耐久。再次按 K 或主动操纵会接管取消。它不具备自动绕障能力，曼巴和佐巴扬模式均不能使用。

自动降落从启动到接地持续复核滑橇承重面、各部件的方块净空和下降通道内的实体，包括玩家、生物、物品和其他直升机。承重面被挖空、出现障碍或实体进入时，都会立即暂停下降并保持高度；原支撑和通道恢复安全后继续原降落程序。按 K 或手动操纵可以取消并接管。本机乘员及本机绳索系统不会阻挡自己的降落。第一人称在面板上亮红色降落占用灯，第三人称在左侧显示“降落暂停”文字，并播报“Terrain. Terrain.”。

电台仅预留 **8 个槽位，不内置音乐**，文件依次命名为 `slot_1.mp3` 至 `slot_8.mp3`。**单人游戏放在本地游戏实例的 `config/no_24_heli_radio/`；多人游戏由服主放在服务器的同名目录**。局域网开放世界由房主提供文件。多人客户端无需自行放歌，也不会使用自己目录中的同名文件替代服务器歌曲。不必填满，空槽位显示“空”。

驾驶员和副驾驶均可按住 Tab、移动鼠标选择槽位后松手播放，选圆盘中心停止。多人首次听到某首歌时自动从服务器后台分片获取，不向玩家显示正在加载音乐的提示，完成校验后按当前进度播放；同一次连接内后续使用缓存，无需重复下载。服务器单曲上限 **32 MiB**，添加或更换歌曲后重启服务器/局域网世界以刷新目录。单人新增文件后重新打开圆盘即可看到，替换当前歌曲后先关台再重选。音乐来源统一为 config，不再使用资源包歌曲后备。

音乐循环播放，后来靠近的玩家从对应进度接入。机内音量不受第三人称镜头远近影响，其他玩家按自身到飞机的距离衰减，64 格外无声；受游戏“唱片机/音符盒”和主音量控制。禁飞警报也不再随镜头拉远而变小。多人下载缓存位于客户端 `config/no_24_heli_radio_cache/`，退出世界、断开服务器或正常关闭游戏时自动清除，下次进入后按需重新获取；自己的 `config/no_24_heli_radio/` 原始音乐不会删除。客户端与服务端均需使用 **2.4.3**。

## 自转迫降

动力丢失后，先降低总距，让下降气流维持旋翼转速；保持机身接近水平和适当的前飞速度。接近地面时拉杆减速并逐渐增加总距，利用旋翼储存的能量减小接地速度。过早大总距会耗尽旋翼能量，过晚拉平会高速撞地。优先放下起落架，避开建筑、水面和陡坡。

这是面向游戏的简化直升机物理，不是现实航空训练程序。高度表是世界 Y 坐标；垂直速度单位为 m/s，空速按 1 格≈1 米换算显示为 km/h。

## 多机显示

机身、内饰、旋翼和起落架使用跨飞机共享的 GPU 网格，逐帧只更新部件矩阵与环境光；机窗保留原透明中心材质。64 格外自动降低曲面细分，近景保持原细节。动态仪表仅在本机第一人称或相机距飞机 6 格内更新，24 格内仍显示静态舱内结构。原版发光描边保留兼容绘制路径。无需额外安装渲染库。

## 乘员、绳降与涂装

下机时按本座同侧门外的真实地面高度寻找站立位置，支持薄停机坪、半砖、台阶和收架后机身较低的情况；最近位置受阻会尝试同侧相邻落点，开门动画结束再复核。正常过程不会跨到另一侧，也不会穿过真实墙壁或把乘员放进障碍中。若整侧被地形或实体卡死，则跳过开门和下机动画，直接按原版方式离开载具：优先落到另一侧可站立点，扩展搜索也没有空间时落在机体顶面，保证玩家不会被困在舱内。

普通登机时，左侧先上左前主驾、再上左后；右侧先上右前副驾、再上右后，总共四人。后排座椅按后舱收窄曲面调整，座椅、乘员和眼位保持对齐。F 或右键自动开门登机，坐稳关门；同侧满员时需绕到另一侧。绳索登机优先右后、左后，后排满后再找右前、左前；任意一座空闲即可登机，四座全满才继续挂绳。主驾就座后，可手持拴绳右键把附近 5 格内的村民装入本侧空座，自动开门、入座并关门；村民不能驾驶。

放绳要求直升机距下方地面 **大于 3 格、不超过 24 格**、水平速度低于 2 m/s、垂速绝对值低于 1.5 m/s。驾驶员按 B 部署，机内玩家按 Y 自动打开本座门，门全开后下绳；非驾驶座的村民在部署时自动下绳。同一根绳可挂多名玩家，各自独立移动；绳上有人时不能收绳，可携带悬挂人员飞行。空绳在飞行中保持展开，按 B 收回。

玩家靠近任意绳段（约 3 格内）按 **Y** 吸附。按住 **W** 上升、**S** 下降，松开立即停住；速度约 2.8 / 4.6 m/s。到顶后按 **E 或 F** 自动开门登机，优先后排，后排坐满后使用任意前排空座，入座后自动关门；四座全满则继续悬挂。进入左前座获得驾驶权，其他座位保持各自权限。总绳长取初始展开长度与当前离地净空的较小值，不随玩家位置收缩。整绳分段模拟惯性，可摆动、弯曲；机身离开视野仍可看见绳段。

绳上按 **Shift** 可主动脱离：离地不超过 3 格时立即释放；超过 3 格时，先警告，松开后须在 3 秒内再次按下确认。主动高空脱离后正常承担后续坠落风险；玩家到达地面后按 Shift 解绳，村民仍自动安全落地。

绿色、白色、黄色、黑色、橙色染料分别合成丛林、雪地、沙漠、纯黑、救援橙涂装。丛林采用橄榄绿、苔绿与深绿斑块；雪地采用冰白、浅灰与蓝灰斑块；沙漠采用沙黄、米色与棕色斑块，三种迷彩覆盖机身、尾梁和尾翼。纯黑采用整片黑色外漆与黑色滑橇；救援橙采用醒目橙色机身、白色腰带与深灰机腹。**紫金24号涂装**由紫色染料 + 黄色染料 + 铁粒 + 玻璃瓶无序合成，采用深紫机身、金色饰带、机腹和滑橇；面向机头的左侧保留原金色“24”，右侧为同风格“Laker”。落地并等待旋翼停转后，手持涂装右键机身。涂装只改变外观。

## 飞行员耳麦与目镜

“飞行员耳麦”和“飞行员目镜”是两件独立装备。背包人物右侧新增耳麦槽和目镜槽，可以同时佩戴，保留原头盔槽。手持右键或 Shift 点击可装入对应空槽，也可直接拖放；创造模式的生存物品栏同样提供这两个槽。两件装备均可在“24号直升机”创造物品栏找到，不提供护甲值。

目镜在第一人称和第三人称前视/后视的夜间均提供夜视，日出日落平滑切换；白天没有目镜画面效果。取下即停止目镜效果，不影响已有夜视药水。耳麦本身不提供夜视。

工作台合成：耳麦三行为「皮革、铁锭、皮革」「铁锭、空、铁锭」「空、红石粉、空」；目镜三行为「铁粒、空、铁粒」「黑色染色玻璃板、空、黑色染色玻璃板」「空、红石粉、空」。

座椅、摇杆和两位乘员整体靠近仪表板，第一人称视点同步前移；两根摇杆底座接入地板，并与座椅留出间距。W/S、A/D 操作时主副驾摇杆同步摆动，两位乘员用右手侧握摇杆，手掌和手臂降低以露出仪表读数。第一人称转头和机体倾斜时，手与摇杆也随座舱保持位置。飞行控制仍由主驾驶负责。

## 难度与配置

在游戏“选项”中打开 **直升机设置**。**我的飞行模式**由每名玩家独立选择，普通玩家也能修改，按 UUID 保存在当前服务器存档中，跨维度、重登及重启保留。飞机按当前驾驶员的模式运行；副驾驶修改自己的模式不影响本机，接任驾驶后才生效。无人驾驶时沿用最后模式。

**全服爆炸破坏 / 着火**仍由房主或具有 2 级权限的管理员统一修改，普通玩家只能查看。关闭后不破坏方块、不点火，但事故爆炸及乘员致命伤害仍存在。

个人模式切换无需重启，仅重置自己正在驾驶的飞机的辅助并取消自动任务；燃油、部件耐久、速度和总距保留。切回休闲默认打开配平与高度保持，**巡航在所有模式下都默认关闭**。

第三人称 HUD 最左下角为燃油、旋翼转速、总距三个表盘，上方为机身模式与自动控制状态。机组信息按前后排两列显示主驾、副驾、左后排、右后排及姓名；空座显示“空座”。底部保留五段连续耐久条。空速表左侧从左到右为垂速、高度两个等大的滚动仪表，顶部显示 m/s 和 m。“垂速”和“高度”标题放大为此前的 1.5 倍。两表刻度与数字统一靠左；垂速每 5 m/s 一条短刻度，整 10 m/s 为带数字的长刻度；高度每 50 米一条短刻度，整 100 米为带数字的长刻度。垂速正值带 +、负值带 -，零刻度只写 0。

两个仪表中央都有箭头固定向左的放大数字窗，外框为向左凸字形：左侧符号和高位区域较矮，右侧低位区域上下加高。垂速仅个位在加高框内连续滚动，十位、百位各只显示一个数字，进位或借位时由下一位滑入、当前位滑出；高度仅十位和个位在加高框内按 00、20、40、60、80 连续滚动，百位及更高位同样采用单行替换。例如 710 米显示 700 与 720 之间的过渡，780 到 800 时百位同步进位。窗内数字与窗外刻度统一：数值增加时向下滚动，减少时向上滚动。正负号固定在窗内左侧中央，与左框保留边距，只显示一次，中心数字为零时隐藏；垂速正数显示 +、负数显示 -，高度正数不加 +、负数显示 -。两个仪表沿用 2/3 整体缩放，并与空速表底部对齐。刻度中心完全不透明，两端渐淡到 50%。高度仍为世界 Y；实际离地高度由近地提示提供。

飞行时按实际离地距离进入 **50 / 30 / 20 / 10 / 5 米**提示档。正常缓降、悬停和爬升只显示普通“离地 X m”，下降率超过当前档的 **6 / 5 / 4.5 / 4 / 3.5 m/s** 时显示“下降过快”。各档均放宽到高于正常辅助下降的约 3.2 m/s，避免正常自动降落误报；异常高速下降仍会警告。只有下降会触发近地语音，同档警告只触发一次，离开该档超过 1 米后重新进入才允许再次触发；接地、入水、未起飞和离机清除状态。近地提示与世界高度表使用不同读数。

| 离地不足 10 格，下降超过 0.1 m/s，未放起落架 | Landing gear. Landing gear.，手动和自动下降均检查 |

所有语音统一管理，同类上一条实际播放完毕后才允许下一条，五档高度也共用这一限制；播放期间的同类请求直接丢弃，不会积压重复播放。双次警告录在同一个音频文件中。起落架警告在条件持续期间只请求一次，恢复安全状态后重新允许；失速警告使用 60%/70% 回差，避免旋翼转速在阈值附近抖动时重复播报。

右上机载雷达半径为 **512 米**，机头方向为上，白色指针为本机，蓝点为玩家、橙点为完好飞机、金色菱形为导航点，红色弧线为禁飞区边界；超出 512 米的导航点钳在外圈指示方向。服务器每半秒提供同维度已加载目标的坐标快照，因此超出客户端完整实体跟踪距离的目标也可显示；不会为扫描强制加载远方区块，最多显示距离最近的 512 个目标。

视角锁定绑定仅在乘机且未打开界面时生效；离机后同键的原版操作保留。雷达方块使用非整块遮挡形状，底部不再使下方地形透视。

首次运行后生成 `config/no_24_heli.json`。其中 `difficulty` 仅作为尚未设置个人模式的默认值。手动修改文件后重启世界/服务器，联机以服务端配置为准。主菜单中的设置编辑本地默认值。

```json
{
  "difficulty": "CASUAL",
  "explosionBlockDamage": true,
  "wind": true,
  "rotorPreSpin": true,
  "fuelCapacity": 1200.0,
  "explosionPower": 5.0,
  "autopilotCruiseKmh": 75.0,
  "autopilotLookMin": 8.0,
  "autopilotLookMax": 30.0,
  "gridCellSize": 2.0,
  "pathSafetyMargin": 2.0,
  "pathBoundaryMargin": 16.0,
  "pathMaxCells": 1000000,
  "pathMaxNodes": 1000000
}
```

- `CASUAL`：休闲模式。默认开配平、高度保持，巡航默认关闭；碰撞伤害较低、预转 5 秒，尾桨失效不施加反扭矩惩罚。允许一键起降。
- `MAMBA`：**曼巴模式**。辅助默认关闭但可手动启用，允许导航自动驾驶；惯性更强、预转 12 秒、油耗更高、尾桨失效惩罚严格，迫降容错更低。禁用一键起降。
- `ZOBAYAN`：**佐巴扬模式**。沿用曼巴物理，配平、高度保持、巡航、导航自动驾驶及一键起降全部禁用；正常带转速飞行也持续损耗机身、旋翼、尾桨，尤其引擎（满转速且持续满足磨损条件时约 2.4 耐久/分钟）。地面不施加该飞行磨损，离机也不提供三秒辅助悬停。
- `explosionBlockDamage=false`：关闭爆炸方块破坏与点火，仍保留载具事故、爆炸实体伤害和乘员致命伤害。
- `wind=false`：关闭风扰动；雨天功率和旋翼效率衰减仍存在。
- `rotorPreSpin=false`：跳过预转等待，依然需要启动引擎并增加总距。
- `fuelCapacity`：100–30000；`explosionPower`：0–12。异常参数会被限制到有效范围。
- 自动驾驶规划配置由服务器统一管理，手动修改后重启世界/服务器；非法非有限数恢复默认值，越界值限制到有效范围并在日志中说明。

| 规划配置 | 默认值 | 允许范围 / 作用 |
|---|---:|---|
| `autopilotCruiseKmh` | 75 | 20–80 km/h，按 20 TPS 换算的巡航目标 |
| `autopilotLookMin` | 8 | 4–16 格，低速前视距离 |
| `autopilotLookMax` | 30 | 最小前视距离–48 格，高速前视上限 |
| `gridCellSize` | 2 | 0.25–64 格；减小可表示更窄通道，但增加网格与搜索成本 |
| `pathSafetyMargin` | 2 | 0–1024 格；在飞机自身规划半径之外增加的禁飞区安全余量 |
| `pathBoundaryMargin` | 16 | 1–4096 格；包围起终点及所有扩张禁飞圆后额外保留的边界空间 |
| `pathMaxCells` | 1000000 | 1–2000000；单次规划可分配的网格数上限 |
| `pathMaxNodes` | 1000000 | 1–2000000；单次规划 A* 可访问节点数上限 |

增加预算不能解决处于真实禁飞圆内的起终点，也不会让被禁飞圆真正封闭的不同区域连通。全维度相距很远的雷达会扩大动态规划矩形，可能触发网格预算；这种情况会报告资源限制，不截断禁飞区数据或假称无路。
